1. Crear Security Group y Llaves SSH en AWS

Local / AWS CLI
aws ec2 create-security-group --group-name cinev2-sg --description "CineV2 SG" --region us-east-1
aws ec2 create-key-pair --key-name cinev2-key --query 'KeyMaterial' --output text --region us-east-1 > cinev2-key.pem && chmod 400 cinev2-key.pem

2. Lanzar Instancia EC2 (t3.micro Free Tier) y Elastic IP

AWS Console / CLI
aws ec2 run-instances --image-id ami-0c7217cdde317cfec --instance-type t3.micro --key-name cinev2-key --security-groups cinev2-sg --block-device-mappings '[{"DeviceName":"/dev/sda1","Ebs":{"VolumeSize":30,"VolumeType":"gp3"}}]'

3. Conectarse y Configurar 4 GB de Memoria Swap

SSH / Instancia EC2
sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile && echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

4. Instalar Docker, Docker Compose, Nginx y Certbot

Instancia EC2
sudo apt update && sudo apt install -y docker.io docker-compose-v2 nginx certbot python3-certbot-nginx && sudo usermod -aG docker $USER

5. Clonar Proyecto y Levantar Ecosistema con Docker Compose

Instancia EC2
git clone <REPO_URL> && cd CINEv2 && docker compose up -d --build && docker exec -it SW2-P2-CINEv2-ms-cinema-core-backend npm run seed:core
