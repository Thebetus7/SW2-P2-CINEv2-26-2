1. Crear Bucket Real en AWS S3

AWS CLI
aws s3api create-bucket --bucket cinev2-media-bucket-prod --region us-east-1

2. Crear Security Group y Lanzar Instancia EC2 t3.micro

aws ec2 run-instances
aws ec2 create-security-group --group-name sg-cinev2-multimedia --description "CineV2 Multimedia" && aws ec2 authorize-security-group-ingress --group-name sg-cinev2-multimedia --protocol tcp --port 22 --cidr 0.0.0.0/0 && aws ec2 authorize-security-group-ingress --group-name sg-cinev2-multimedia --protocol tcp --port 5175 --cidr 0.0.0.0/0

3. Conectar por SSH y Crear Swap de 4GB

SSH / Instancia EC2
sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile && echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

4. Instalar Docker y Levantar el Manifiesto de AWS

docker compose
sudo apt-get update && sudo apt-get install -y docker.io docker-compose-v2 git && sudo usermod -aG docker $USER && git clone https://github.com/<ORG>/CINEv2.git && cd CINEv2 && docker compose -f docker-compose.aws.yml up -d
