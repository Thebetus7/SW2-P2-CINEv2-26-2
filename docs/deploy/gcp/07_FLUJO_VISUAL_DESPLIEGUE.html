1. Reservar IP Estática y Crear Regla de Firewall en GCP

Local / Google Cloud CLI
gcloud compute addresses create cinev2-static-ip --region=us-central1 && gcloud compute firewall-rules create allow-cinev2-http-https-ssh --allow tcp:22,tcp:80,tcp:443 --target-tags=cinev2-server

2. Provisionar Máquina Virtual e2-micro (Always Free)

gcloud compute
gcloud compute instances create cinev2-vm-prod --zone=us-central1-a --machine-type=e2-micro --image-family=ubuntu-2204-lts --image-project=ubuntu-os-cloud --boot-disk-size=30GB --boot-disk-type=pd-standard --tags=cinev2-server --address=cinev2-static-ip

3. Conectar por SSH y Crear Swap de 4GB

SSH / Instancia GCP
sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile && echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

4. Instalar Docker, Docker Compose y Nginx

apt-get
sudo apt-get update && sudo apt-get install -y docker.io docker-compose-v2 nginx certbot python3-certbot-nginx && sudo usermod -aG docker $USER

5. Clonar Proyecto y Levantar Contenedores

docker compose
git clone https://github.com/<ORG>/CINEv2.git && cd CINEv2 && docker compose build --parallel && docker compose up -d
