1. Crear Resource Group y Reglas NSG en Azure

Azure CLI
az group create --name rg-cinev2-azure --location eastus && az network nsg create --resource-group rg-cinev2-azure --name nsg-cinev2-auth --location eastus && az network nsg rule create --resource-group rg-cinev2-azure --nsg-name nsg-cinev2-auth --name AllowAuth --priority 1000 --destination-port-ranges 22 5174 8081 5176 8001 --protocol Tcp --access Allow

2. Crear la Máquina Virtual B1s (Free Tier)

az vm create
az vm create --resource-group rg-cinev2-azure --name vm-cinev2-auth-node --image Ubuntu2204 --size Standard_B1s --os-disk-size-gb 64 --storage-sku StandardSSD_LRS --admin-username ubuntu --generate-ssh-keys

3. Conectar por SSH y Crear Swap de 4GB

SSH / VM
sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile && echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

4. Instalar Docker y Levantar el Manifiesto de Azure

docker compose
sudo apt-get update && sudo apt-get install -y docker.io docker-compose-v2 git && sudo usermod -aG docker $USER && git clone https://github.com/<ORG>/CINEv2.git && cd CINEv2 && docker compose -f docker-compose.azure.yml up -d
