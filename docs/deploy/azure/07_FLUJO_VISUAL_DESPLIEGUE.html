1. Crear Resource Group y Network Security Group (NSG)

Local / Azure CLI
az group create --name rg-cinev2-prod --location eastus && az network nsg create --resource-group rg-cinev2-prod --name nsg-cinev2 --location eastus

2. Crear VNet, IP Pública Estática y Máquina Virtual B1s

az vm create
az vm create --resource-group rg-cinev2-prod --name vm-cinev2-prod --image Ubuntu2204 --size Standard_B1s --os-disk-size-gb 64 --storage-sku StandardSSD_LRS --admin-username ubuntu --generate-ssh-keys

3. Conectar por SSH y Crear Swap de 4GB

SSH / VM Azure
sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile && echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

4. Instalar Docker, Docker Compose y Nginx

apt-get
sudo apt-get update && sudo apt-get install -y docker.io docker-compose-v2 nginx certbot python3-certbot-nginx && sudo usermod -aG docker $USER

5. Clonar Repositorio y Desplegar Contenedores

docker compose
git clone https://github.com/<ORG>/CINEv2.git && cd CINEv2 && docker compose build --parallel && docker compose up -d

6. Configurar Nginx Reverse Proxy y Habilitar SSL Let's Encrypt

certbot / HTTPS
