# Regla de Transparencia y Visibilidad de Comandos Git

## Contexto y Propósito
Para fomentar el aprendizaje continuo y proporcionar contexto visual en tiempo real de las operaciones sobre el sistema de control de versiones.

## Directrices Operativas Obligatorias
1. **Visibilidad en el Chat**:
   - Siempre que se vaya a ejecutar o se ejecute cualquier operación, script o comando relacionado con Git (por ejemplo: `git status`, `git add`, `git commit`, `git push`, `git checkout`, `git branch`, `git pull`, `git rebase`, `git merge`, `git stash`, etc.), se debe mostrar de forma explícita en el chat el comando exacto antes o al momento de su ejecución.

2. **Formato de Presentación**:
   - Presentar el comando en un bloque de código claramente visible, indicando una breve explicación didáctica de lo que hace para reforzar el aprendizaje continuo:
     ```bash
     git <comando> [parámetros]
     ```
   - Explicar brevemente la intención técnica del comando en el contexto actual del proyecto.
